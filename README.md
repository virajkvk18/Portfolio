## ⚡ Overview

A dual-focus portfolio built with clean vanilla web architecture, modern typography, and motion design. It seamlessly bridges **computational thinking** (applied AI/ML, backend pipelines, and interactive frontends) with **high-craft visual design** (brand identities, editorial typography, and packaging systems).

There are **zero build steps** and **zero package dependencies**—delivering near-instant first contentful paint (FCP), 60fps animations, and full accessibility compliance.

```
Portfolio/
├── index.html                   # Main Portfolio: Engineering, AI/ML, Experience & Contact

├── virajgraphicdesigner/        # Dedicated Graphic Design Portfolio Page

└── assets/                      # Production-optimized thumbnails, logos & portraits
```

## ✨ Key Highlights

### 1. Dual-Track Presentation
* **AI/ML & Engineering Showcase** ([`/`](https://viraj-pi.vercel.app/)): Features 12+ real-world products and experiments including RAG pipelines, healthcare diagnostic triage agents, Web3 escrow protocols, and algorithmic problem-solving milestones.
* **Dedicated Graphic Designer Page** ([`/virajgraphicdesigner`](https://viraj-pi.vercel.app/virajgraphicdesigner)): Tailored specifically for design leads, art directors, and hiring managers. Features high-res brand systems, packaging mocks, editorial posters, and client case studies.

### 2. Interactive Features
* **Live Design & Typography Lab**: Test live font pairings (*Syne*, *Serif*, *Inter Tight*, *Mono*) and color harmonies in real-time.
* **Interactive Palette Switchers**: Instant visual direction toggles (*Electric*, *Citrus*, *Coral*, *Noir*) with fluid CSS transitions.
* **Full Case Study Lightbox**: Deep-dive modals with design challenges, creative rationale, deliverables, and click-to-copy color hex codes.
* **Dynamic Category Filtering**: Seamlessly filter between *Brand Identity*, *Posters*, *Packaging*, and *Social Campaigns*.
* **One-Click Share Utility**: Instantly copy direct portfolio URLs with toast confirmations.

### 3. Engineering & Performance Excellence
* **Zero Dependencies**: Lightweight native HTML5, CSS3, and ES6+ JavaScript.
* **Accessibility**: Fully keyboard operable (`Tab`, `Esc` modal dismiss, focus rings), semantic landmarks, and `prefers-reduced-motion` compliance.
* **SEO & Social Open Graph**: Rich meta tags, Twitter card previews, and favicon assets for high-engagement link sharing.

## 💻 Local Development

Run the portfolio locally with any static web server:

### Option 1: Python
```powershell
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) or [http://localhost:8000/virajgraphicdesigner/](http://localhost:8000/virajgraphicdesigner/) in your browser.

### Option 2: Node.js (`npx serve`)
```powershell
npx serve .
```
